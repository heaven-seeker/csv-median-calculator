# CSV Median Calculator

## 1. Описание приложения
Консольное приложение для анализа потоковых биржевых данных. Программа сканирует указанную директорию, считывает данные из подходящих CSV-файлов, объединяет их в хронологическом порядке и инкрементально вычисляет медиану цены. Результаты расчетов (изменения медианы) фиксируются в результирующем файле `median_result.csv` с точностью до 8 знаков после запятой.

## 2. Требования
- **Компилятор**: с поддержкой стандарта C++23
- **Система сборки**: CMake (минимальная версия 3.23)
- **Зависимости системы**: `Boost` (модуль `program_options`)
- **Встроенные зависимости** (загружаются автоматически через FetchContent):
    - `toml++` (v3.4.0) — парсинг конфигурации
    - `spdlog` (v1.17.0) — быстрое логирование

## 3. Сборка проекта
Для сборки проекта используйте стандартный пайплайн CMake.
*Примечание: Если Boost установлен через vcpkg, укажите путь к toolchain-файлу при конфигурации.*

```bash
# Клонирование репозитория
git clone <URL_репозитория>
cd csv_median_calculator

# Конфигурация
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release

# Компиляция
cmake --build build --config Release
